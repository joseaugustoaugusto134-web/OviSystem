Perguntas frequentes

  • O OviSystem é gratuito?

    Sim. Este é um protótipo acadêmico e pode ser usado livremente para fins de estudo e demonstração.

  • Preciso instalar algum programa?

    Não. O OviSystem funciona direto do navegador, tanto no computador quanto no celular.

  • Quantos animais eu posso cadastrar?

    Não há limite de cadastro. O sistema foi pensado para criadores de pequena e média escala, mas comporta rebanhos maiores.

  • Como funciona o controle sanitário?

    Você registra vacinas, vermífugos e ocorrências de doenças para cada animal, com histórico completo e alertas automáticos de vencimento.

  • É possível registrar a genealogia dos animais?

    Sim. É possível vincular pai e mãe de cada ovelha para montar uma árvore genealógica simplificada.

  • Meus dados ficam salvos com segurança?

    Os dados ficam vinculados à sua conta, acessível somente após login.
